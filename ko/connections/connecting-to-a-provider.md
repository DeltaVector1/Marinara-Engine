# AI 제공자에 연결하기

이 가이드에서는 캐릭터가 답변할 수 있도록 Marinara Engine을 AI 제공자에 연결하는 방법을 설명합니다. 연결을 만들고, API 키를 붙여넣고, 모델을 고르고, 제대로 작동하는지 확인하는 순서입니다.

## 연결이란

연결은 하나의 AI 서비스에 접속하는 데 필요한 정보를 한데 모아 저장해 둔 것입니다. 연결 하나에는 네 가지가 담깁니다. 제공자, API 키 또는 로그인 정보, 기본 URL(서비스의 웹 주소), 그리고 모델입니다.

API 키는 AI 제공자가 발급하는 비밀 문자열입니다. 비밀번호와 같은 역할을 합니다. 이 키가 있어야 Marinara가 AI 서비스와 통신하고 그곳의 계정을 쓸 수 있습니다. Marinara는 API 키를 암호화해서 저장하며, 연결을 내보낼 때 키는 절대 함께 나가지 않습니다.

Marinara Engine은 미리 만들어 둔 연결이나 무료 체험용 키를 제공하지 않습니다. 새로 설치한 직후에는 연결이 하나도 없습니다. 채팅을 시작하려면 먼저 연결을 하나 이상 만들어야 합니다.

## Connections 패널 열기

연결은 앱 오른쪽의 **Connections**(연결) 패널에서 관리합니다.

연결이 하나도 없는 상태에서 채팅을 시작하려고 하면 **Set Up**(설정) 창이 나타납니다. 이 창에는 **Open Connections**(연결 열기) 버튼이 있습니다. 이 버튼을 클릭하면 **Connections** 패널로 바로 이동합니다.

패널 위쪽에는 버튼이 3개 있습니다. 아이콘만 표시되고 글자 라벨은 없습니다.

- **New**(더하기 아이콘)를 클릭하면 **Create Connection**(연결 만들기) 창이 열립니다.
- **Import**(아래쪽 화살표 아이콘)는 파일에서 연결을 불러옵니다.
- **Select**(체크 표시 아이콘)는 여러 개 선택 기능을 켭니다. 여러 연결을 한 번에 내보내거나 삭제할 때 씁니다.

## 연결 만들기

첫 제공자를 추가하는 순서입니다.

1. **Connections** 패널에서 **New** 버튼(더하기 아이콘)을 클릭하세요.
2. **Create Connection** 창에서 연결의 **Name**(이름)을 입력하세요. 나중에 알아보기 쉬운 이름이 좋습니다. 예를 들면 `GPT-4o Main`입니다.
3. **Provider**(제공자) 아래에서 사용할 서비스의 버튼을 클릭하세요. 예를 들어 **OpenAI**, **Anthropic**, **OpenRouter**입니다.
4. **Create**(만들기)를 클릭하세요. Marinara가 연결을 만들고 그 연결의 전체 편집 화면인 **Connection Editor**(연결 편집기)를 엽니다.
5. **API Key**(API 키) 입력란을 찾으세요. 제공자에서 받은 키를 여기에 붙여넣으세요. 아직 키가 없다면 입력란 아래의 **Get your {Provider} API key** 링크를 클릭하세요. 이 링크는 브라우저에서 제공자의 키 발급 페이지를 엽니다.
6. **Model**(모델) 드롭다운을 열고 모델을 고르세요. **Search models…** 입력란에 입력하면 목록을 좁힐 수 있습니다. 목록이 비어 있으면 **Fetch Models from API**(API에서 모델 가져오기)를 클릭해 계정에서 쓸 수 있는 모델을 불러오세요. Marinara는 가져온 목록을 연결과 함께 저장하므로, 나중에 채팅 입력란의 모델 메뉴에서도 다시 가져오지 않고 목록을 보여 줄 수 있습니다.
7. **Save**(저장)를 클릭하세요. 위쪽의 상태 문구가 **Saved**로 바뀝니다.

나중에는 편집기를 열지 않고도 모델을 바꿀 수 있습니다. Quick Connection Switcher(빠른 연결 전환기, 채팅 입력란의 링크 아이콘)나 **Chat Settings → Connection**(채팅 설정 → 연결)의 **Model** 필드를 사용하세요. [랜덤 풀과 Quick Connection Switcher](organizing-connections.md#the-random-pool-and-quick-connection-switcher)를 참고하세요.

**Base URL**(기본 URL) 입력란은 대개 건드릴 필요가 없습니다. 알려진 제공자라면 Marinara가 알아서 채웁니다. 프록시나 로컬 서버를 쓸 때만 바꾸세요.

지원하는 제공자 전체 목록과 각각의 기본 설정, 키를 받는 곳은 [지원하는 AI 제공자](providers-reference.md)에서 확인하세요.

API 키 대신 로컬 로그인을 쓰는 제공자도 있습니다. 이런 제공자에는 **API Key** 입력란이 없습니다. [Claude, ChatGPT, Grok 구독 연결](subscription-clis.md)을 참고하세요.

내 컴퓨터에서 돌아가는 모델에 연결하려면 [로컬 모델 또는 자체 호스팅 모델 연결하기](local-self-hosted.md)를 참고하세요.

## 연결 테스트하기

**Connection Editor** 아래쪽에는 **Connection Tests**(연결 테스트) 카드가 있습니다. 채팅을 시작하기 전에 설정이 제대로 되었는지 여기서 확인하세요.

1. **Test Connection**을 클릭하세요. API 키가 제공자에서 통하는지 확인합니다. 성공하면 응답 시간과 함께 초록색 **Connection Test: Success** 줄이 나타납니다.
2. **Send Test Message**(테스트 메시지 전송)를 클릭하세요. 고른 모델에 "hi"라는 단어를 보내고 답변을 보여 줍니다. 성공하면 초록색 **Test Message: Success** 줄이 나타나고 그 아래에 모델의 답변이 표시됩니다.

**Send Test Message** 버튼은 모델을 고르기 전까지 비활성화 상태입니다. 테스트가 실패하면 줄이 빨간색으로 바뀌고 오류 내용을 보여 줍니다. 이 문구만 봐도 키가 틀렸는지, 모델 이름이 잘못되었는지 같은 원인을 대개 알 수 있습니다.

## 채팅에 사용할 연결 고르기

연결은 그 자체로는 아무 일도 하지 않습니다. 어떤 연결을 쓸지는 채팅마다 따로 정합니다.

1. 채팅을 연 다음 **Chat Settings**(채팅 설정)를 여세요.
2. **Connection** 섹션을 찾으세요.
3. 드롭다운에서 쓸 연결을 고르세요.

드롭다운에는 특별한 선택지가 2개 더 있습니다. **None**은 아직 연결을 고르지 않았다는 뜻입니다. **🎲 Random**(Random 앞에 주사위 아이콘이 붙습니다)은 무작위 후보 목록에서 매번 다른 연결을 고릅니다. Game Mode(게임 모드)에서도 항목 이름은 그대로 **Connection**이지만, 그 안의 드롭다운 라벨은 **GM / Party Model**입니다.

채팅을 새로 만들면 **Set Up** 창이 먼저 연결을 고르라고 안내합니다. 하나를 고른 다음 **Create Chat**(채팅 생성)을 클릭하세요.

## 자주 나는 오류

테스트나 메시지 전송이 실패하면 다음부터 확인하세요.

- **API Key**가 틀렸거나 만료된 경우. 연결을 열어 키를 다시 붙여넣은 다음 **Save**를 클릭하세요.
- 모델을 고르지 않은 경우. **Model**을 고르기 전까지 **Send Test Message**는 비활성화 상태입니다.
- 다른 제공자의 키를 넣은 경우. 제공자마다 자기 키가 따로 필요합니다. **Provider**를 바꾸면 **API Key** 입력란은 의도적으로 비워집니다.
- **Base URL**이 차단되었거나 접속되지 않는 경우. 로컬 서버나 프록시 서버를 직접 돌리는 것이 아니라면 비워 두고 제공자 기본값을 쓰세요.

연결과 생성 관련 오류의 해결 방법은 [Marinara Engine 문제 해결](../TROUBLESHOOTING.md)에 더 정리되어 있습니다.
