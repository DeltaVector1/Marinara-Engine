# 채팅 설정 개요

이 가이드에서는 채팅 하나만 따로 손볼 수 있는 **Chat Settings**(채팅 설정) 패널을 설명합니다. 여기서 정하는 기본 항목인 채팅 이름, 연결, 저장해 둔 설정 묶음을 다룹니다. 패널에 들어 있는 나머지 기능은 각각의 자세한 가이드로 안내합니다.

이 패널의 설정은 모두 현재 채팅에만 적용됩니다. 설정을 바꿔도 다른 채팅에는 영향이 없습니다.

## Chat Settings 패널 열기

패널은 채팅을 연 상태에서 엽니다.

1. 아무 채팅이나 여세요.
2. 채팅 툴바에서 채팅 설정 톱니바퀴 버튼을 클릭하세요(툴팁에 **Chat Settings**라고 표시됩니다).
3. **Chat Settings** 패널이 옆에서 열립니다.

톱니바퀴 아이콘이 붙은 **Chat Settings** 패널이 보입니다. 새 채팅을 만들면 바로 설정할 수 있도록 이 패널이 자동으로 열립니다.

## Chat Name

**Chat Name**(채팅 제목) 섹션에는 채팅 목록에 표시되는 이름이 들어 있습니다. 이 이름은 본인에게만 보입니다. AI에는 전달되지 않으며, 주고받는 내용에도 전혀 영향을 주지 않습니다.

1. **Chat Name** 섹션에서 현재 이름을 클릭하세요.
2. 이름이 입력란으로 바뀝니다.
3. 새 이름을 입력하세요.
4. Enter를 누르거나 체크 표시 버튼을 클릭해 확정하세요.

## Connection

**Connection**(연결) 섹션에서는 이 채팅에서 어떤 AI 제공자와 모델이 답할지 정합니다. 연결은 API 키와 선택한 모델까지 포함해 AI 제공자에 접속하는 데 필요한 정보를 한데 저장해 둔 것입니다. API 키는 해당 제공자의 계정을 Marinara Engine이 쓸 수 있게 해 주는 비밀번호 같은 비밀 문자열입니다.

드롭다운에서 저장해 둔 연결을 고르세요. **Random**을 고를 수도 있습니다. 이때는 무작위 목록에 넣어 둔 연결 중에서 매번 다른 연결을 고릅니다.

연결을 처음부터 만드는 방법은 [AI 제공자에 연결하기](../connections/connecting-to-a-provider.md)를 참고하세요.

## 설정 프로필

패널 맨 위에는 **Profile**(프로필) 컨트롤이 있습니다. 설정 프로필은 채팅 설정을 한 묶음으로 저장해 두고 다른 채팅에서 다시 쓸 수 있게 한 것입니다. 드롭다운에서 프로필을 고르면 현재 채팅에 적용됩니다.

프로필에는 이 채팅의 연결, 프롬프트 프리셋, 에이전트, 도구, 번역, 기억 기능, 고급 매개변수를 비롯한 설정이 함께 담깁니다. 캐릭터, 페르소나, 로어북, 스프라이트, 요약, 태그, 장면 프롬프트는 프로필이 건드리지 않습니다. 이 항목들은 채팅 자체에 묶여 있습니다.

이 줄에는 글자 없이 작은 아이콘 버튼만 늘어서 있습니다. 버튼에 마우스를 올리면 툴팁에 이름이 나타납니다.

- 디스크 아이콘(**Save current chat settings into this profile**)은 현재 채팅의 설정을 선택한 프로필에 써 넣습니다.
- 연필 아이콘(**Rename profile**)은 선택한 프로필의 이름을 바꿉니다.
- 파일 더하기 아이콘(**Save current chat settings as a new profile**)은 현재 채팅의 설정을 새 프로필로 저장합니다.
- 아래쪽 화살표 아이콘(**Import settings profile (.json)**)은 `.json` 파일에서 프로필을 불러옵니다.
- 위쪽 화살표 아이콘(**Export settings profile (.json)**)은 선택한 프로필을 `.json` 파일로 저장합니다.
- 휴지통 아이콘(**Delete profile**)은 선택한 프로필을 삭제합니다.

드롭다운 옆에는 별 버튼이 있습니다. 이 버튼을 클릭하면 그 프로필이 해당 모드의 새 채팅에 쓰이는 기본값이 됩니다. 그 모드에서 새 채팅을 만들면 Marinara가 별을 붙인 프로필을 알아서 적용합니다. 기본값으로 지정할 수 있는 프로필은 모드마다 하나뿐입니다.

이 기능을 지원하는 모드에는 기본 제공 **Default** 프로필이 있습니다. **Default** 프로필은 이름을 바꾸거나, 설정을 써 넣거나, 삭제할 수 없습니다. 이 프로필을 적용하면 프로필이 관리하는 설정이 앱 기본값으로 되돌아갑니다.

프로필 컨트롤은 Game Mode에는 나타나지 않습니다.

Marinara는 **preset**이라는 말을 프롬프트 프리셋에만 씁니다. 프롬프트 프리셋은 시스템 프롬프트의 구조와 생성 파라미터를 정하고, 설정 프로필은 위에 적은 재사용 가능한 채팅 설정을 한데 묶습니다. 자세한 규칙은 [설정 프로필](settings-profiles.md)을 참고하세요.

## 채팅 변수

**Chat Variables**(채팅 변수) 섹션에서는 텍스트에 이름을 붙이고 그 이름을 중괄호 두 개로 감싸 재사용할 수 있습니다. `char1`이라는 변수에 `Mary` 값을 넣은 다음 메시지에 `{{char1}} walks in.`을 입력하면 AI는 "Mary walks in."으로 읽습니다.

각 행에는 **name**(이름)과 **value**(값)이 있습니다. 이름에는 영문자, 숫자, 밑줄을 쓸 수 있으며 영문자나 밑줄로 시작해야 합니다. 정확히 21자인 이름은 캐릭터 참조용으로 예약되어 있습니다. `char`나 `user` 같은 기본 제공 매크로 이름은 사용할 수 없습니다. 기본 제공 매크로가 항상 우선하기 때문입니다. Enter를 누르거나 필드 밖을 클릭하면 저장됩니다. 휴지통 버튼은 변수를 삭제합니다.

다음 세 가지를 알아 두세요.

- 메시지에는 입력한 태그가 그대로 표시됩니다. 값은 AI만 봅니다. 따라서 나중에 값을 바꾸면 그 태그를 사용한 이전 턴에도 모두 반영됩니다.
- 변수는 이 채팅에만 속합니다. 다른 채팅에는 별도 목록이 있으며 현재 목록은 앱을 다시 시작해도 유지됩니다.
- `{{setvar}}`와 같은 저장소를 사용합니다. 프롬프트 섹션이나 로어북 항목이 설정한 값도 여기에서 편집할 수 있는 행으로 표시됩니다. 같은 이름을 사용하는 항목은 직접 입력한 값을 덮어씁니다.

중괄호 두 개 안에 쓸 수 있는 다른 내용은 [프롬프트 매크로](../prompts/macros.md)를 참고하세요.

## 패널의 다른 섹션

**Chat Settings** 패널에는 채팅별로 동작하는 기능도 여럿 모여 있습니다. 기능마다 별도의 가이드가 있습니다.

- **Persona**(페르소나)에서는 이 채팅에서 맡을 역할을 정합니다. Conversation(대화)과 Roleplay(롤플레이) 채팅에 나타납니다. [채팅에서 페르소나 선택하기](../characters/choosing-your-persona.md)를 참고하세요.
- **Characters**(캐릭터)에서는 Conversation과 Roleplay 채팅의 캐릭터를 관리합니다. 캐릭터가 둘 이상인 채팅은 [그룹 채팅과 여럿이 나누는 대화](group-chats.md)를 참고하세요.
- **Party**(파티)는 Game 채팅에만 나타납니다. **Persona**와 **Characters** 섹션을 대신해 두 가지를 한곳에 모아 놓은 섹션입니다.
- **Lorebooks**(로어북)에서는 이 채팅에 세계 설정을 붙입니다. [로어북 개요](../lorebooks/overview.md)를 참고하세요.
- **Agents**(에이전트)에서는 이 채팅에 쓸 AI 에이전트를 켭니다. [에이전트: 채팅을 도와주는 AI](../agents/agents-overview.md)를 참고하세요.
- **Translation**(번역)에서는 메시지 자동 번역을 설정합니다. [메시지 번역](../integrations/message-translation.md)을 참고하세요.
- **Advanced Parameters**(고급 매개변수)에서는 temperature나 최대 토큰 수 같은 생성 설정을 이 채팅에서만 다르게 지정합니다. [생성 파라미터](../prompts/generation-parameters.md)를 참고하세요.

어떤 섹션이 보이는지는 채팅 모드에 따라 다릅니다. Roleplay, Conversation, Game 채팅에만 나타나는 섹션도 있습니다.
