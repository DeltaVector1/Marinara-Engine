# Подключение к провайдеру ИИ

В этом руководстве вы узнаете, как подключить приложение Marinara Engine к провайдеру ИИ, чтобы персонажи могли отвечать. Вы создадите подключение, вставите ключ API, выберете модель и проверите, что все работает.

## Что такое подключение

Подключение – это сохраненные настройки доступа к одному сервису ИИ. В каждом подключении хранятся четыре вещи: провайдер, ключ API или вход в аккаунт, базовый адрес (веб-адрес сервиса) и модель.

Ключ API – это секретный код, который выдает провайдер ИИ. Он работает как пароль. Благодаря ему Marinara обращается к сервису ИИ от имени вашего аккаунта. Marinara шифрует ключ перед сохранением, и при экспорте подключения ключ в файл не попадает.

Приложение Marinara Engine не поставляется ни с готовым подключением, ни с бесплатным пробным ключом. Сразу после установки подключений нет ни одного. Прежде чем начать чат, нужно создать хотя бы одно подключение.

## Открытие панели **Connections**

Подключениями вы управляете в панели **Connections** (подключения) справа в приложении.

Если подключений еще нет и вы пытаетесь начать чат, Marinara показывает окно **Set Up** (настройка). В этом окне есть кнопка **Open Connections**. Нажмите ее, чтобы сразу перейти в панель **Connections**.

Сверху в панели расположены три кнопки. На них только иконки, без подписей.

- Кнопка **New** (значок плюса) открывает окно **Create Connection**.
- Кнопка **Import** (значок стрелки вниз) импортирует подключения из файла.
- Кнопка **Select** (значок в виде галочки) включает массовое выделение, чтобы экспортировать или удалить сразу несколько подключений.

## Создание подключения

Чтобы добавить первого провайдера, выполните эти шаги.

1. В панели **Connections** нажмите кнопку **New** (значок плюса).
2. В окне **Create Connection** введите название подключения в поле **Name**. Пусть оно будет узнаваемым, например `GPT-4o Main`.
3. В разделе **Provider** нажмите кнопку нужного сервиса, например **OpenAI**, **Anthropic** или **OpenRouter**.
4. Нажмите кнопку **Create**. Marinara создает подключение и открывает для него полный редактор **Connection Editor**.
5. Найдите поле **API Key**. Вставьте сюда ключ, полученный у провайдера. Если ключа еще нет, нажмите ссылку **Get your {Provider} API key** под полем. Она открывает страницу ключей провайдера в браузере.
6. Откройте раскрывающийся список **Model** и выберите модель. Список можно отфильтровать, набрав текст в поле **Search models…**. Если список пуст, нажмите кнопку **Fetch Models from API**, чтобы получить модели, доступные вашему аккаунту. Marinara сохраняет полученный список вместе с подключением, поэтому меню моделей в области ввода сообщения потом может показать его без повторной загрузки.
7. Нажмите кнопку **Save**. Текст статуса вверху меняется на **Saved**.

Позже модель можно сменить, не открывая редактор: воспользуйтесь панелью Quick Connection Switcher (значок ссылки в области ввода сообщения) или полем **Model** в **Chat Settings → Connection**. См. [Случайный набор и панель Quick Connection Switcher](organizing-connections.md#the-random-pool-and-quick-connection-switcher).

Поле **Base URL** обычно трогать не нужно: для известных провайдеров Marinara заполняет его автоматически. Меняйте его только при работе через прокси или локальный сервер.

Полный список поддерживаемых провайдеров, их настройки по умолчанию и адреса, где взять ключ, собраны в руководстве [Поддерживаемые провайдеры ИИ](providers-reference.md).

Некоторые провайдеры используют вход в аккаунт вместо ключа API. У них поля **API Key** нет. См. [Подключения по подписке Claude, ChatGPT и Grok](subscription-clis.md).

Как подключить модель, запущенную на вашем компьютере, описано в руководстве [Подключение локальной модели или модели на своем сервере](local-self-hosted.md).

## Проверка подключения

Внизу редактора **Connection Editor** есть карточка **Connection Tests**. С ее помощью убедитесь, что все настроено верно, еще до начала чата.

1. Нажмите кнопку **Test Connection**. Она проверяет ключ API у провайдера. При успехе появляется зеленая строка **Connection Test: Success** со временем ответа.
2. Нажмите кнопку **Send Test Message**. Она отправляет слово "hi" выбранной модели и показывает ответ. При успехе появляется зеленая строка **Test Message: Success**, а под ней – ответ модели.

Кнопка **Send Test Message** остается недоступной, пока не выбрана модель. Если проверка не удалась, строка становится красной и показывает ошибку. Обычно по этому сообщению понятно, что исправить: неверный ключ или неизвестную модель.

## Выбор подключения для чата

Само по себе подключение ничего не делает. Каждый чат выбирает, какое подключение использовать.

1. Откройте чат, затем откройте его панель **Chat Settings** (настройки чата).
2. Найдите раздел **Connection**.
3. Выберите подключение из раскрывающегося списка.

В этом списке есть еще два особых пункта. Значение **None** означает, что подключение пока не выбрано. Значение **🎲 Random** (перед словом Random стоит значок кубика) каждый раз берет другое подключение из случайного набора. В режиме Game Mode раздел по-прежнему называется **Connection**, но раскрывающийся список внутри подписан **GM / Party Model**.

При создании нового чата окно **Set Up** сначала просит выбрать подключение. Выберите его, затем нажмите кнопку **Create Chat**.

## Частые ошибки

Если проверка или тестовое сообщение не проходит, посмотрите сначала вот на что:

- Неверный или истекший ключ в поле **API Key**. Откройте подключение, вставьте ключ заново и нажмите кнопку **Save**.
- Модель не выбрана. Кнопка **Send Test Message** остается недоступной, пока не выбрана модель в списке **Model**.
- Ключ от другого провайдера. Каждому провайдеру нужен свой ключ. При смене значения **Provider** поле **API Key** очищается намеренно.
- Заблокированный или недоступный адрес в поле **Base URL**. Оставьте его пустым, чтобы работал адрес провайдера по умолчанию. Исключение – локальный сервер или прокси.

Другие способы устранить ошибки подключения и генерации собраны в руководстве [Устранение неполадок в приложении Marinara Engine](../TROUBLESHOOTING.md).
