# Character Sprites

Sprites are images you upload to a character or persona. Marinara can show them in Roleplay when the Expression Engine agent is enabled. This guide covers manual upload, management, and export.

## Add sprites

1. Open the character or persona editor.
2. Select **Sprites**.
3. Choose **Facial Expressions** or **Full-body**.
4. Add a sprite name, then upload an image from your device. Use **Upload Folder** to add several named images at once.

The file name becomes the sprite name when you upload a folder. Use common expression names such as `happy`, `sad`, or `angry` when you want an expression agent to match them.

## Manage and export

Use the controls on an image to rename, download, or delete it. You can export one sprite category or the full sprite set as a ZIP file from the **Sprites** tab.

Marinara Native character and persona exports include their sprites. Compatible character card formats do not preserve Marinara-specific sprite data. See [Character Import and Export](import-export.md).

## Show sprites in Roleplay

Install **Expression Engine** from **Agents → Download Agents**, then enable it for the Roleplay chat in **Chat Settings → Agents**. Select which characters or persona can show sprites and choose the available sprite categories in the agent settings.

Sprites you upload remain attached to their character or persona when you use that card in Conversation. Conversation does not display sprite overlays.
