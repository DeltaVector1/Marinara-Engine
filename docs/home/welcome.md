# Getting Started with Marinara Engine

Marinara is a local app for chatting and roleplaying with AI characters. Connect a local or hosted model, then create or import a character and start a chat.

## Home screen

Home shows recent chats, links to the main panels, documentation, and the first-time tutorial. Open **Documentation** to search the guide library or **Replay Tutorial** to review the guided tour.

## Start your first chat

1. Install Marinara and open it in your browser. See [Installation](../INSTALLATION.md).
2. Add a model connection. See [Connecting to an AI Provider](../connections/connecting-to-a-provider.md).
3. Create or import a character in the **Characters** panel. See [Creating and Editing Characters](../characters/creating-and-editing-characters.md).
4. Open the chat list, choose **Conversation** or **Roleplay**, then select **New Chat**. Choose a connection, persona, and character in the setup panel.

## Chat modes

- **Conversation** is a direct-message style chat. See [Conversation setup](../conversation/getting-started.md).
- **Roleplay** is a story scene with narration, characters, and optional character art. See [Roleplay setup](../roleplay/getting-started.md).

## Get help

Read the [FAQ](../FAQ.md), open **Documentation** in Marinara, or see [Troubleshooting](../TROUBLESHOOTING.md). For community help, use the **Discord** link in the app.
