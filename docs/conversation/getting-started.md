# Conversation Mode: Getting Started

Conversation is a direct-message style chat with one or more characters. This guide covers setup and the main controls.

## Start a conversation

1. Open the chat list and select **Conversation**.
2. Select **New Chat**.
3. Choose a name, model connection, persona, and one or more characters.
4. Select **Create Chat** to open the conversation.

A chat with one character is a private conversation. Add more characters to start a group chat. See [Group Chats](../chats/group-chats.md) for turn-taking options.

## Profiles and prompts

The **Convo** tab in the character editor holds a Conversation display name, About Me, and behavior fields. These fields apply only in Conversation. See [Conversation Profiles](profiles.md).

You can choose a prompt preset for the chat and change it later in Chat Settings. See [Prompt Presets](../prompts/presets.md).

## Messages and media

Use the composer to send a message. The chat supports editing, alternate replies, regeneration, and guided generation. See [Sending and Streaming](../chats/sending-and-streaming.md) and [Message Actions](../chats/messages.md).

You can import or export a chat from its chat menu. See [Chat Import and Export](../chats/export-import.md).

Conversation supports calls, character selfies, and custom emoji, stickers, and GIFs when those options are configured. See [Calls](calls.md), [Selfies](selfies.md), and [Custom Emoji and Stickers](emoji-stickers-gifs.md).
