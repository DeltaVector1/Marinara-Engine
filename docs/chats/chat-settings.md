# Chat Settings Overview

Chat Settings controls the open chat. It includes the model connection, character and persona choices, prompt settings, optional agents, and chat-specific display options. The available sections depend on whether the chat uses Conversation or Roleplay.

## Open Chat Settings

Open a chat and select **Chat Settings** from the chat toolbar. Select a section to view or edit its settings. New chat setup asks for the same core choices before the chat opens.

Most settings apply only to the current chat. App-wide appearance and provider settings live in **Settings** and **Connections**.

## Common sections

- **Connection** selects the provider connection and model for replies. See [Connecting to an AI Provider](../connections/connecting-to-a-provider.md).
- **Persona and Characters** selects who is speaking and the identity you use. See [Choosing Your Persona](../characters/choosing-your-persona.md).
- **Prompt Preset** selects the prompt structure for the chat. See [Prompt Presets](../prompts/presets.md).
- **Lorebooks** adds world information to the prompt. See [Lorebooks](../lorebooks/overview.md).
- **Agents** configures optional helpers for the chat. See [Agents](../agents/agents-overview.md).
- **Advanced Parameters** overrides generation settings for this chat. See [Generation Parameters](../prompts/generation-parameters.md).
- **Gallery** stores media attached to the chat. See [Scene Backgrounds](../media/scene-backgrounds.md) and [Scene Video](../media/scene-video.md).

## Settings profiles

A settings profile saves reusable chat configuration. It does not replace the chat's messages or characters. See [Settings Profiles](settings-profiles.md).
