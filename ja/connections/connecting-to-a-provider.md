# AIプロバイダーへの接続

このガイドでは、キャラクターが返信できるようにMarinara EngineをAIプロバイダーへつなぐ手順を説明します。接続を作り、APIキーを貼り付け、モデルを選び、動作を確認するところまで進みます。

## 接続とは

接続とは、1つのAIサービスへの到達方法をMarinara Engineに教えるための保存済みの設定です。1つの接続には4つの情報が入ります。プロバイダー、APIキーまたはログイン、ベースURL(サービスのアドレス)、そしてモデルです。

APIキーは、AIプロバイダーから受け取る秘密の文字列です。パスワードのようなものだと考えてください。このキーがあることで、MarinaraはAIサービスと通信し、そこのアカウントを利用できます。Marinaraはキーを暗号化して保存し、接続をエクスポートするときもキーは一切含めません。

Marinara Engineには、あらかじめ用意された接続も、無料のお試しキーも付いていません。インストール直後の接続は0件です。チャットを始めるには、まず接続を1つ以上作る必要があります。

## Connectionsパネルを開く

接続の管理は、画面右側の**Connections**(接続)パネルで行います。

接続が1つもない状態でチャットを始めようとすると、Marinaraは**Set Up**(セットアップ)ウィンドウを表示します。このウィンドウには**Open Connections**ボタンがあり、クリックすると**Connections**パネルへ直接移動できます。

パネル上部には3つのボタンが並んでいます。表示はアイコンだけで、文字のラベルはありません。

- **New**(新規作成、プラスのアイコン)は**Create Connection**(接続の作成)ウィンドウを開きます。
- **Import**(インポート、下向き矢印のアイコン)はファイルから接続を読み込みます。
- **Select**(選択、チェックマークのアイコン)は複数選択をオンにして、いくつもの接続をまとめてエクスポートしたり削除したりできるようにします。

## 接続を作成する

最初のプロバイダーを追加する手順は次のとおりです。

1. **Connections**パネルで**New**ボタン(プラスのアイコン)をクリックします。
2. **Create Connection**ウィンドウで、接続の**Name**(名前)を入力します。後から見てすぐわかる名前にしてください。たとえば`GPT-4o Main`などです。
3. **Provider**(プロバイダー)の下で、使いたいサービスのボタンをクリックします。たとえば**OpenAI**、**Anthropic**、**OpenRouter**などです。
4. **Create**(作成)をクリックします。Marinaraが接続を作り、その接続の**Connection Editor**(接続エディター)を開きます。
5. **API Key**(APIキー)欄を探し、プロバイダーで取得したキーを貼り付けます。まだキーがない場合は、欄の下にある**Get your {Provider} API key**のリンクをクリックしてください。ブラウザーでプロバイダーのキー発行ページが開きます。
6. **Model**(モデル)ドロップダウンを開いてモデルを選びます。**Search models…**の欄に文字を入力すると、一覧を絞り込めます。一覧が空のときは**Fetch Models from API**をクリックすると、アカウントで使えるモデルを読み込みます。Marinaraは取得した一覧を接続と一緒に保存します。そのため、チャット入力欄のモデルメニューでも、あとから取得し直さずに一覧を表示できます。
7. **Save**(保存)をクリックします。上部付近の状態表示が**Saved**に変わります。

あとからモデルを変更するときは、エディターを開く必要はありません。Quick Connection Switcher(チャット入力欄のリンクアイコン)か、**Chat Settings → Connection**(チャット設定 → 接続)の**Model**欄を使います。[ランダムプールとQuick Connection Switcher](organizing-connections.md#the-random-pool-and-quick-connection-switcher)を参照してください。

**Base URL**(ベースURL)欄は、ふつう触る必要はありません。既知のプロバイダーならMarinaraが自動で入力します。プロキシやローカルサーバーを使う場合だけ変更してください。

対応しているプロバイダーの一覧、それぞれのデフォルト設定、キーの入手先については[対応しているAIプロバイダー](providers-reference.md)を参照してください。

一部のプロバイダーは、APIキーではなくローカルのログインを使います。その場合は**API Key**欄が表示されません。詳しくは[Claude、ChatGPT、Grokのサブスクリプション接続](subscription-clis.md)を参照してください。

自分のコンピューターで動かしているモデルにつなぐ方法は、[ローカルモデルやセルフホストモデルへの接続](local-self-hosted.md)を参照してください。

## 接続をテストする

**Connection Editor**の下部には**Connection Tests**(接続テスト)カードがあります。チャットを始める前に、ここで設定が正しく動くか確かめられます。

1. **Test Connection**をクリックします。APIキーがプロバイダーで通るかを確認します。成功すると、応答時間を添えた緑色の**Connection Test: Success**の行が表示されます。
2. **Send Test Message**をクリックします。選んだモデルに「hi」という単語を送り、その返信を表示します。成功すると緑色の**Test Message: Success**の行が表示され、その下にモデルの返答が出ます。

**Send Test Message**ボタンは、モデルを選ぶまで押せません。テストが失敗すると行が赤くなり、エラーが表示されます。キーの間違いや存在しないモデルなど、直すべき点はたいていこのメッセージからわかります。

## チャットで使う接続を選ぶ

接続は、それ単体では何もしません。どの接続を使うかは、チャットごとに選びます。

1. チャットを開き、その**Chat Settings**(チャット設定)を開きます。
2. **Connection**の項目を探します。
3. ドロップダウンから接続を選びます。

このドロップダウンには特別な選択肢が2つあります。**None**は接続をまだ選んでいない状態です。**🎲 Random**(Randomの前にダイスのアイコンが付きます)は、ランダムプールの中から毎回違う接続を選びます。Game Modeでも項目名は**Connection**のままですが、その中のドロップダウンには**GM / Party Model**というラベルが付きます。

チャットを新しく作るときは、**Set Up**ウィンドウが先に接続の選択を求めます。1つ選んでから**Create Chat**をクリックしてください。

## よくあるエラー

テストやメッセージが失敗したときは、まず次の点を確かめます。

- **API Key**が間違っているか、期限が切れています。接続を開いてキーを貼り直し、**Save**をクリックします。
- モデルを選んでいません。**Model**を選ぶまで**Send Test Message**は押せません。
- 別のプロバイダーのキーを使っています。プロバイダーごとに専用のキーが必要です。**Provider**を切り替えると、**API Key**欄は意図的に空になります。
- **Base URL**がブロックされているか、到達できません。ローカルサーバーやプロキシを動かしているのでなければ、空欄のままにしてプロバイダーのデフォルトを使ってください。

接続や生成のエラーへの対処をもっと知りたいときは、[Marinara Engineのトラブルシューティング](../TROUBLESHOOTING.md)を参照してください。
